#### Step 1: Install Main Distribution Panel
**Location**: Grid D4 + (0", 0") - Electrical closet

- Spaces: 42 circuits
- Type: Main lugs only (MLO)

7. Bond panel enclosure to building ground system
8. Install directory holder and temporary schedule

4. **Lock** main panel door with project lock #2025-0847

7. **Test** voltage tester before and after each use
